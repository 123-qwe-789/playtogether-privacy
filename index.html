《玩在一起》隐私政策

生效日期：2026 年 9 月 17 日

开发者：李月旺（月淤泥）

联系方式：3020881172@qq.com

1. 引言

「玩在一起」（应用包名：com.liyuewang.playtogether，以下简称"本应用"）是一款纯离线的聚会玩法合集。我们非常重视你的隐私。本政策说明本应用如何处理（以及为什么不处理）你的信息。

一句话概括：本应用不联网、不收集、不上传任何个人信息，你输入的玩家昵称、玩法设置与自定义题库只保存在本机应用沙箱内，随时可在应用内一键清空，卸载应用即全部删除。

2. 我们收集哪些信息（数据收集类型）

本应用不收集任何个人信息。具体说明如下：

常见信息类型本应用是否收集说明
手机号 / 邮箱 / 账号❌ 不收集本应用无注册、无登录、无账号体系
设备标识（IMEI / OAID / MAC 等）❌ 不收集不调用任何设备标识接口
位置信息❌ 不收集未申请定位权限，不调用定位能力
相册 / 通讯录 / 麦克风 / 摄像头❌ 不收集未申请上述任何权限
剪贴板 / 已安装应用列表❌ 不收集不读取
玩家昵称（你在应用内手动输入）⚠️ 仅本机存储由你手动输入，用于本机界面显示与下次打开时自动回填；只保存在本机应用沙箱内，不上传，可在应用内一键清空、卸载即删除
玩法设置（跳过次数、轮数、角色配置、音效与震动开关）⚠️ 仅本机存储用于下次打开时沿用你上次的设置；只保存在本机应用沙箱内、不上传，可在应用内一键清空
自定义题库（你粘贴的题目与词对）⚠️ 仅本机存储由你自行粘贴导入，仅用于本机玩法出题；只保存在本机应用沙箱内、不上传，可在应用内删除或一键清空
隐私政策同意状态⚠️ 仅本机存储为实现本政策首次展示与"已同意"记录，在本机保存一个布尔标记（不含任何个人信息），卸载应用即删除

3. 信息的使用目的

由于本应用不收集个人信息，不存在"信息使用目的"。上述"玩家昵称"仅用于在本机界面中显示当前轮到谁这一玩法功能；玩法设置与自定义题库仅用于沿用你的设置与在本机出题；"同意状态标记"仅用于避免每次启动重复弹出本政策。这些数据都不会离开你的设备。

上述数据不会被用于广告、营销、个性化推荐或用户画像 —— 本应用不含任何广告位，也不依赖第三方做推荐。

4. 第三方共享、转让与公开披露

本应用不与任何第三方共享、转让或公开披露任何信息。

  • 本应用未集成任何第三方 SDK（包括但不限于统计分析、广告、推送、崩溃上报、社交分享类 SDK）；
  • 本应用不具备网络访问能力（未申请网络权限），不存在向任何服务器（含境外服务器）传输数据的可能；
  • 不存在数据跨境传输。

5. 数据的存储与保存期限

  • 本应用不产生云端数据，没有任何服务器存储你的信息；
  • 本机保存的数据共 4 类：① 玩家昵称（用于下次打开时自动回填）② 玩法设置（跳过次数、轮数、角色配置、音效与震动开关）③ 自定义题库（你粘贴导入的题目与词对内容）④ 隐私政策同意状态标记；
  • 上述数据全部保存在本应用自己的沙箱目录内（其他应用无法读取），不会上传到任何服务器；
  • 玩法过程中的临时数据（当前牌面、身份分配、投票状态等）只存在于设备内存中，退出页面或关闭应用即释放；
  • 保存期限：直到你在应用内「设置 → 数据 → 清空本地数据」清除、在系统应用中清除本应用数据，或卸载本应用；
  • 卸载本应用后，本应用产生的全部本地数据随之删除，无残留。

6. 你的权利

由于本应用不收集你的个人信息，通常无需行使查阅、更正、删除等权利。你仍然可以：

  1. 查看本政策与用户协议：随时可在应用内「设置 → 关于」中打开完整内容；也可访问发布页 本页 与 用户协议；
  2. 清除本地数据：在应用内「设置 → 数据 → 清空本地数据」一键清除（玩家昵称、玩法设置与自定义题库一并清除，保留隐私政策同意状态）；也可在系统「设置 → 应用和服务 → 应用管理 → 玩在一起 → 存储」中清除数据；
  3. 撤回同意：卸载本应用即可；卸载后本应用无法再运行，也就不再处理任何数据；
  4. 联系我们：如对本政策有任何疑问、意见或投诉，请发送邮件至 3020881172@qq.com，我们将在收到邮件后 7 个工作日内回复。

7. 未成年人保护

本应用为全年龄适用的聚会玩法，不含联网功能、不含内容推荐、不含任何付费项目，也不会收集未成年人的任何信息。若你是未成年人，请在监护人指导下使用；监护人如有疑问，可通过上述邮箱联系我们。
